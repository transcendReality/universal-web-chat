# Universal Web Chat Browser Extension - Usage Guide

This guide provides instructions on how to use the Universal Web Chat browser extension after installation.

## Installation

### Chrome, Edge, or Brave
1. Download the extension package for your browser from the releases page
2. Extract the ZIP file to a location on your computer
3. Open your browser and navigate to the extensions page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
4. Enable "Developer mode" using the toggle in the top-right corner
5. Click "Load unpacked" and select the extracted folder for your browser
6. The extension should now appear in your browser toolbar

### Firefox
1. Download the Firefox extension package from the releases page
2. Open Firefox and navigate to `about:addons`
3. Click the gear icon and select "Install Add-on From File..."
4. Select the downloaded .xpi file
5. Follow the prompts to complete installation

## Basic Usage

### Starting a Chat

1. Navigate to any website
2. Click the Universal Web Chat icon in your browser toolbar
3. The chat window will appear as an overlay on the current page
4. You are now connected to the chat room for the current website

### Chat Interface

The chat interface includes:

- **Chat Window**: Displays messages from you and other users
- **Input Field**: Type your messages here
- **Send Button**: Click to send your message
- **Settings Button**: Access settings and preferences
- **Minimize Button**: Minimize the chat window

### Moving the Chat Window

1. Hover over the top bar of the chat window
2. Click and hold to drag the window to a new position
3. Release to place the window

### Minimizing and Restoring

1. Click the minimize button (−) in the top-right corner to minimize
2. Click the chat icon in the bottom-right corner to restore

## Settings and Preferences

Access settings by clicking the gear icon (⚙️) in the chat window or by clicking the extension icon and selecting "Settings" in the popup.

### Available Settings

- **Display Name**: Set your name as it appears to other users
- **Theme**: Choose between Light, Dark, or System Default
- **Notifications**: Enable or disable chat notifications
- **Auto-Connect**: Automatically connect to chat rooms when visiting websites
- **Show on All Pages**: Enable chat on all websites or only specific ones

## Privacy Considerations

- All communication is peer-to-peer and encrypted
- No messages are stored on any central server
- Your display name is visible to other users in the same chat room
- The extension only connects you with others visiting the same website

## Troubleshooting

### Chat Not Connecting

1. Check your internet connection
2. Ensure WebRTC is not blocked by your browser or network
3. Try refreshing the page
4. Check if the website uses content security policies that might block the extension

### Messages Not Sending

1. Verify you're connected to the chat room (green connection indicator)
2. Check if other users are present in the room
3. Try reconnecting by clicking the extension icon and selecting "Reconnect"

### Extension Not Working on Certain Sites

Some websites with strict security policies may block extension functionality. Try:

1. Checking the browser console for errors
2. Temporarily disabling other extensions that might conflict
3. Ensuring the site is not in your extension's block list
